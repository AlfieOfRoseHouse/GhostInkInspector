# GhostInk Inspector
**Coding Langages**: HTML / CSS / JS | **Category**: Utility

A simple web tool that allows you to uncover and describe unicode characters hidden within your text, and can clean it too.

**-- How it works --**

- Built with _HTML_, _CSS_, _JS_
- Highlights hidden unicode characters and converts them into readable text
- When hovering over one of these markings a tooltip appears
- The copy buttons can copy the original text or the cleaned version of your text (warning sometimes these characters are useful eg when writing in mongolian or using emojis)

**--**

**-- Usage --**

1. Open
   [Use!](https://alfieofrosehouse.github.io/GhostInkInspector/)
2. Paste your text into the text editor
3. And you have your text highlighting any invisible characters
4. Press the copy clean button to copy a version without these characters to your clipboard
